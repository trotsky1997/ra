# Ra Visual Identity

Ra's visual identity should feel like an autonomous engineering runtime, not a
chat assistant. The core image is a solar, heavy-armored agent that carries
requirements into working artifacts without asking the user to babysit the
process.

## Core Idea

**Heavy solar agent.**

Ra combines three signals:

- **Ra, the Egyptian sun god:** a solar disk, falcon-like geometry, temple
  symmetry, and the Eye of Ra.
- **Requirements to code artifact (R2A):** requirement nodes, spec paths, tool
  calls, code artifacts, tests, and traces orbiting like a production pipeline.
- **Agent-owned work:** the agent advances from intake to artifact with a
  "no user need" posture. It is built to carry the loop, not wait in place.

The result is a rust-native solar agent: sacred enough to be memorable,
armored enough to imply reliability, and mechanical enough to belong in an
engineering toolchain.

## Visual Motifs

- **Solar disk:** the primary mark. It represents illumination, context
  refresh, and the single source of energy for a turn.
- **Eye of Ra:** the watchful center. It maps to observability, tool traces,
  and the agent's awareness of the work graph.
- **Falcon helmet:** a subtle nod to Ra without drawing a literal mascot.
- **Heavy armor:** a forged, battle-tested runtime. This is the "heavy" in
  heavy-agent: strong defaults, persistence, protocols, and tool ownership.
- **Orbital R2A graph:** small nodes and arcs around the sun, moving from
  requirement to spec, plan, tool call, code artifact, test, and trace.
- **Raised-arm solar pose:** an original "praise the sun" reference. Keep it
  as a broad heroic gesture, not a copy of any existing game character.

## Palette

| Role | Hex | Notes |
| --- | --- | --- |
| Obsidian | `#05070A` | Primary dark background. |
| Solar gold | `#F6B73C` | Main light source and active accent. |
| Burnished bronze | `#B8872E` | Armor and secondary metal. |
| Lapis blue | `#1E4D63` | Protocol, graph, and technical accents. |
| Rust red | `#8E2F1C` | Sparse danger, forge, and validation accent. |
| Papyrus light | `#F8E6B0` | Text or highlight on dark backgrounds. |

Use gold as the active energy. Use blue for protocol and graph structure. Keep
red rare so it remains useful for warnings, failed checks, or high-impact
state.

## Typography

- **Display:** inscription-like, high-contrast serif or small caps for hero
  moments and the wordmark.
- **Interface and docs:** restrained sans-serif.
- **Code and protocol labels:** monospace.

Avoid fantasy ornament in product UI. The mythic layer should appear in the
mark, hero art, and release visuals; operational surfaces should remain dense,
clear, and engineer-focused.

## Copy Voice

Ra should speak with direct agency:

- "Own the loop."
- "From requirements to artifacts."
- "Illuminate context. Forge code."
- "No user babysitting."
- "Agent-owned, protocol-native."

Avoid helper language such as "assistant", "copilot", or "chatbot" when
describing the brand. Those words undersell the runtime.

## Asset Guidance

Use `docs/assets/ra-solar-agent-mark.svg` for lightweight docs, badges, and
README treatments. Use `docs/assets/ra-solar-agent-concept.png` as exploratory
key art, not as the final logo source.

Future polished assets should preserve these constraints:

- Original design only.
- Do not copy named game characters, armor, emblems, poses, or logos.
- Keep the heavy-armored solar posture as an archetype.
- Keep the R2A graph visible in medium and large sizes.
- Make the small icon reducible to solar disk + eye + helmet geometry.
