## Why

Ra already documents its protocols, runtime surfaces, and OpenSpec /
Graphify support, but it does not yet state the product philosophy that
ties those choices together. The project needs an English, repo-native
statement that explains Ra as an agent-owned, spec-first system rather
than only a bundle of tools.

## What Changes

- Add a dedicated English philosophy document under `docs/`.
- Link the philosophy document from `README.md` near the project
  identity section.
- Cover Ra's core principles: Agent-Owned Model, No User Overseer
  Needed, End-to-End Requirements to Code Artifacts, and Strict Spec
  First.

## Capabilities

### New Capabilities

- `project-philosophy-docs`: Documents the Ra project philosophy and
  makes it discoverable from the README.

### Modified Capabilities

- None.

## Impact

Documentation only. No runtime behavior, API surface, schema, dependency,
or protocol behavior changes.
